## 📌 About

A powerful cybersecurity tool that analyzes password strength by checking multiple security criteria. This tool helps users create stronger passwords by providing instant feedback on password security.

---

## ✨ Features

| Feature | Description | Status |
|---------|-------------|--------|
| 🔐 Length Check | Validates minimum password length (8+ characters) | ✅ |
| 🔠 Uppercase Letters | Checks for uppercase characters (A-Z) | ✅ |
| 🔡 Lowercase Letters | Checks for lowercase characters (a-z) | ✅ |
| 🔢 Numbers | Ensures numeric characters (0-9) are present | ✅ |
| 🎯 Special Characters | Validates special character usage (!@#$% etc.) | ✅ |
| 📊 Strength Score | Provides overall strength rating (0-100) | ✅ |

## 🚀 Installation

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Steps

```bash
# Clone the repository
git clone https://github.com/Sudharshana262/Password-Strength-Analyzer.git

# Navigate to project directory
cd Password-Strength-Analyzer

# Install required dependencies
pip install -r requirements.txt

# Run the application
python main.py
